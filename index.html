Fotobox Apt-Repository

Pakete fuer Raspberry Pi OS (arm64). Distributionen: bookworm, trixie. Komponenten: main (Releases), nightly.

Einrichten auf dem Pi

sudo mkdir -p /etc/apt/keyrings
# Repo ist nicht signiert, daher trusted=yes
. /etc/os-release
echo "deb [arch=arm64 trusted=yes] https://bene726.github.io/Fotobox_qt6 $VERSION_CODENAME main" | sudo tee /etc/apt/sources.list.d/fotobox.list
sudo apt update && sudo apt install fotobox

Fuer Nightlies zusaetzlich die Komponente nightly in die Zeile aufnehmen.
