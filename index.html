Fotobox Apt-Repository

Pakete fuer Raspberry Pi OS (arm64). Distributionen: bookworm, trixie. Komponenten: main (Releases), nightly.

Einrichten auf dem Pi

sudo mkdir -p /etc/apt/keyrings
curl -fsSL https://bene726.github.io/Fotobox_qt6/fotobox.gpg | sudo tee /etc/apt/keyrings/fotobox.gpg >/dev/null
. /etc/os-release
echo "deb [arch=arm64 signed-by=/etc/apt/keyrings/fotobox.gpg] https://bene726.github.io/Fotobox_qt6 $VERSION_CODENAME main nightly" | sudo tee /etc/apt/sources.list.d/fotobox.list
sudo apt update && sudo apt install fotobox

Hinweis: Es gibt noch kein Release, main ist daher leer. Die Zeile oben enthaelt deshalb auch nightly. Nach dem ersten Release genuegt main.
